# 哲マロ(ぬ) 設計書

2026-10-14 に、ぬぬはらとの相談で決めた内容。実装の正本。変えたら、ここも直す。

## 1. 何を作るか

相談を投げると、代表的な思想の哲学者たち（7人）と、開発者ぬぬはらから回答が届く Web サービス。
いろんな考え方を見比べて、自分に合う答えを見つける。見つけた答えは、同じ悩みを持つ人に共有できる。

- **一番大事な体験: いろんな哲学者の考え方と意見が、分かりやすく得られること**
- 使う人: 悩みのある人なら誰でも（一般向け）。スマホ中心、日本語のみ
- 運用費はゼロ。AI は Gemini API の無料枠だけを使う
- ログインは無い（性癖カルテと同じく、端末に持ち主の鍵を覚える）

### 最初に出す範囲

相談 → 7人の回答（届いた順に出る）→ 比べ表・ワンタップの補足・「刺さった」・自分の答え → 共有／みんなの相談（テーマ・哲学者・言葉で探す）／共有ページと OGP／哲学者の名簿ページ／ぬぬはらの欄（関連マシュマロ＋AIぬぬはら）／重い相談の窓口／通報と管理画面／規約・プライバシー／年代・性別（任意）／38人の絵

### 後回し（作りは備えておく）

- 大人向け（seiheki.net の下）。相談に `mode`（general / adult）を持たせ、アドレスで切り替える作りにしておく。今は general だけ開く
- 哲マロ白書（年代別に刺さる哲学者、多い悩み…）。そのためのデータは最初から保存する
- 端末の引き継ぎ（性癖カルテの引き継ぎ URL の形を写す）
- note・YouTube のデータ（マシュマロとほぼ重なる）
- 共有用の画像の生成
- ぬぬはらの関連回答を、文字の近さから意味の近さ（埋め込み）に替える

## 2. 画面と体験

### トップ `/`
- 大きな相談の入力欄（1000字まで）と「哲学者に聞く」
- 入力欄の下に、任意の「年代」「性別」（答えなくても送れる）
- 入力欄の近くに一言だけ「名前や学校名など、個人が分かることは書かないでください」（無料枠では相談文が Google の改善に使われうるため。規約にも書く）
- 書きかけの相談は端末に残す（送れなかったときも消えない）
- 下に「みんなの相談」（共有された相談の新着。大分類で絞れる）と、哲学者の名簿への入口

### 待ち
- 選ばれた哲学者が一人ずつ「考えています…」→ 書き上がった人からカードが出る（ストリーミング）
- 全員の分を待たせない

### 相談のページ `/c/:id`
持ち主が開くと編集できる。共有されていれば誰でも見られる。共有されていない相談を持ち主以外が開くと 404。

1. 相談文
2. **比べ表**: 7人の「結論の一言」（30字以内）を縦に並べる。行は哲学者の色。押すとその人のカードへ
3. **哲学者のカード**（7枚）
   - 絵・名前・時代・分野（哲学／心理学／実践の知恵）・学派
   - 「この人の考え方」1行
   - 結論の一言（太く）
   - 回答（250〜400字。その人らしい語り口）
   - **考え方のもと**: 回答が使った概念（名簿の番号から）と代表作。概念名・学派名を押すと、下から短い補足が出る
   - 名言（名簿にあるものだけ。出典付き）
   - 死や苦しみを扱う思想（ショーペンハウアー・カミュ・セネカなど）のときは「哲学者の思想の紹介で、死を勧めるものではありません」と添える
   - 「刺さった」ボタン
4. 「ほかの哲学者にも聞く」: 名簿の残りから2人足す（AI をもう1回）
5. **ぬぬはらの欄**
   - 「ぬぬはらの過去の回答」: 近いマシュマロ回答 1〜3件（質問と回答の抜粋、元のマシュマロのページへのリンク）
   - 「AIぬぬはら」: 近い回答を手本に AI が書いた回答。「本人の発言ではありません」と明記
6. **自分の答え**（任意）: 刺さった人を選び、自分なりの答えを一言（200字まで）
7. **みんなに共有**: 公開の前に相談文を直せる。名前は匿名が既定、ニックネームも付けられる（20字まで）。公開すると X に投稿できる。あとで非公開に戻せる。消すこともできる
8. 重い相談のときは、回答の上に相談窓口（いのちの電話・よりそいホットラインなど）を出す
9. 共有されたページでは: 相談者が刺さった人と「自分の答え」、見た人の「刺さった」の数（「この相談で刺さった人が多いのは〇〇」）、「似た悩みのみんなの相談」、「自分も相談する」、通報

### みんなの相談 `/search`
- 「言葉」「大分類・小分類」「刺さった哲学者」で絞れる。並びは新しい順／刺さった数の順
- テーマ別の一覧 `/theme/:category` は検索の入口にもなる

### 哲学者の名簿 `/philosophers`・`/philosophers/:id`
- 38人を時代・分野ごとに並べる
- 一人のページ: 絵・中心の考え・代表作・概念（補足つき）・名言・その人が刺さった相談

### その他
- 自分の相談の一覧（この端末の分）
- 規約 `/terms`・プライバシー `/privacy`・管理画面 `/admin`
- 最下部に開発者情報と関連サービス（性癖カルテの DeveloperFooter と同じ内容。関連サービスの並びはエゴサ支援ツールと同じ）

- 「ほかの哲学者にも聞く」は、まだ出ていない人から2人

## 4. 回答の作り方（AI）

### 1回の相談で Gemini を呼ぶのは1回
- ぬぬはらの関連回答は、サーバーで文字の近さ（2文字ずつの TF-IDF）から探す。API を呼ばない（後で埋め込みに替えられるよう、探す処理は1つの関数にまとめる）
- 生成を1回だけ呼び、改行区切りの JSON（1行1つ）でまとめて返させる:
  1. `{"type":"meta","category":…,"tags":[…],"crisis":bool,"picks":[7人の id]}`
  2. `{"type":"answer","philosopher":id,"conclusion":…,"body":…,"concepts":[概念の番号],"quote":名言の番号|null}` × 7
  3. `{"type":"nunu","body":…}`
- 届いた行から順に検証（zod）して画面へ流す。名簿にない概念・名言の番号は捨てる。**名言の本文は名簿から差し込む**（AI に書き写させない）
- 指示文の固定の前半に、38人ぶんの名簿（中心の考え・概念・名言の番号・言わせないこと・語り口）を入れる。後半に相談文と、ぬぬはらの手本（近い3件）
- 「ほかの哲学者にも聞く」は、出ていない人から2人だけを答えさせる（もう1回）

### モデル
- TopicStream と同じく、混んでいたら（503・時間切れ・一時的な 429）次のモデルへ。モデルの一覧は `worker/gemini/models.ts` の1か所
- 1日の上限（429 で日の枠を使い切った）なら、その日は受付を止め「今日の相談の受付は終わりました」を出す。書いた相談は端末に残る。みんなの相談はいつでも読める
- キーが無いとき（手元・テスト）は偽の AI が決まった回答を返す

### 精確さを確かめる仕組み
- 試験用の相談 20件（`scripts/eval/cases.json`）を本物の Gemini にかけ、全員の回答を Markdown に書き出すスクリプト（`npm run eval`）。読み比べて名簿と指示文を直す

## 5. ぬぬはらのデータ

- マシュマロの公開回答（2026-10-14 時点で 92件。文字で取れる）をスクリプトで取る（`npm run nunu:fetch`）。一覧は `https://marshmallow-qa.com/users/3745329/answers`（続きは `?before=<最後の updated_at>`、404 で終わり）、1件は `https://marshmallow-qa.com/messages/<uuid>`
- 1件ずつ: 質問・回答・URL・日付・**一般／大人の印**・大分類。`shared/nunu/answers.json` に置く
- 一般／大人の印は、最初は自動で付け、ぬぬはら本人に確かめてもらう（`docs/nunu-review.md` に一覧を書き出す）
- 一般向けでは、大人の印の回答は関連回答にも AIぬぬはらの手本にも使わない
- 画面では抜粋と、元のマシュマロのページへのリンク
- 回答が増えたら同じスクリプトを再実行する

## 6. 保存・共有・分類・集計

### D1 の表（`migrations/`）
- `owners`: 端末の持ち主（鍵のハッシュ）。Cookie `owner` で見分ける（性癖カルテの owner.ts の簡略版）
- `consultations`: id／持ち主／本文／mode／大分類／小分類（JSON）／重い相談の印／年代・性別（任意）／作った時刻／共有した時刻／公開名／自分の答え／相談者が刺さった人（JSON）／隠した時刻（管理）／使ったモデル／状態（完成・途中）
- `answers`: 相談 × 哲学者。順番・結論・本文・概念（JSON）・名言の番号
- `nunu_answers`: 相談ごとの AIぬぬはらの本文と、関連したマシュマロ回答の番号
- `hearts`: 見た人の「刺さった」（相談 × 哲学者 × 押した人のハッシュ。同じ人は1回）
- `reports`: 通報
- `shared_fts`: 共有された相談の全文検索（FTS5 trigram）。共有・非公開に戻す・隠す・消すで出し入れする
- `ai_usage`: 日ごとの呼び出し数・失敗数（上限に近いかを見る）

### 公開と非公開
- 非公開の相談は持ち主だけ。消すまで残る。いつでも消せる（回答・刺さった・検索の索引ごと消す）
- 共有したあとで非公開に戻せる

### 分類
- 大分類 10（恋愛／家族／友人・人間関係／仕事／学校・勉強／お金／自分のこと／生き方・将来／心と体／死・別れ）＋その他
- 小分類 50ほど（`shared/themes.ts`）。どちらも決まった表から AI に選ばせる（表にないものは捨てる）。管理画面で直せる

### 探す
- 言葉: 3文字以上は FTS5 trigram、2文字以下は LIKE（共有された相談だけ）
- 似た悩み: 同じ大分類の中で、小分類が多く重なる順 → 新しい順

### 集計用のデータ（哲マロ白書に備える）
- 年代・性別（任意）、大分類・小分類、選ばれた哲学者、刺さった哲学者（相談者・見た人）、時間帯、共有したか
- 出すときは5人未満の集計を出さない（性癖カルテと同じ決まり）。非公開の相談も「数としてだけ」集計に入ることを規約に書く

## 7. 構成

- Cloudflare Workers（Hono）＋ D1 ＋ 静的アセット ＋ Rate Limiting ＋ Turnstile。無料枠
- 画面: React 19 ＋ React Router ＋ Tailwind CSS 4 ＋ Vite（@cloudflare/vite-plugin）
- 検証: zod
- アドレス: `https://tetsumaro.oshilog.life`（oshilog.life は Cloudflare の DNS）。最初は workers.dev でも動かす
- デプロイ: GitHub に push すると Cloudflare の Workers Builds が出す（性癖カルテと同じ）。手元からは本番に出さない

### フォルダ
- `shared/`: 画面と Worker で共用する純粋な処理とデータ（名簿・学派・テーマ・指示文の組み立て・答えの読み取り・近さの計算・ぬぬはらのデータ）
- `worker/`: API（`routes/`）、D1（`db/`）、Gemini（`gemini/`）、持ち主・連投対策・Turnstile・OGP
- `src/`: 画面（`pages/`・`components/`）
- `public/portraits/`: 38人の絵（SVG）
- `scripts/`: マシュマロの取得、回答の質の確かめ
- `test/`（Worker と純粋な処理）、`e2e/`（画面の流れ。偽の AI）

### API
| | |
|---|---|
| `POST /api/consult` | 相談を送る。改行区切りの JSON で流す（start → meta → answer×7 → nunu → done／error） |
| `POST /api/consultations/:id/more` | ほかの哲学者を2人足す（同じく流す） |
| `GET /api/consultations/:id` | 持ち主か、共有されていれば誰でも |
| `PATCH /api/consultations/:id` | 持ち主: 自分の答え・刺さった人・公開名・（共有前の）本文 |
| `PUT/DELETE /api/consultations/:id/share` | 共有する／非公開に戻す |
| `DELETE /api/consultations/:id` | 消す |
| `POST /api/consultations/:id/hearts` | 見た人の「刺さった」 |
| `GET /api/me/consultations` | この端末の相談 |
| `GET /api/shared` | みんなの相談（q・category・tag・philosopher・sort・cursor） |
| `GET /api/shared/:id/similar` | 似た悩み |
| `POST /api/reports` | 通報 |
| `/api/admin/*` | 通報の一覧・隠す・分類を直す（ADMIN_TOKEN） |

### 連投対策
- 相談を送るときに Turnstile（シークレットが入っているときだけ）
- Rate Limiting: 相談は回線ごとに1分3回、書き込み・読み込み・通報・検索は性癖カルテと同じ考え方
- 1つの端末から1日10相談まで（D1 で数える）
- 相談は1000字、自分の答えは200字、公開名は20字まで

## 8. 見た目

- 雑誌のような、安心感のあるおしゃれなフラットデザイン
- 哲学者の絵: **上半身のデフォルメを、面で塗り分けたポリゴン風**（16Personalities のような雰囲気だが、絵柄は真似しない）。淡い背景に、その人らしいしぐさ・小物（ソクラテスは人差し指を立てる、ニーチェは腕組み…）。38人を同じ決まり（`docs/portrait-style.md`）でコード（SVG）で描く。気に入らない人は後で画像に差し替えられる
- 画面: 淡い背景・白いカード・余白多め・角丸。哲学者ごとの色をカード・比べ表・名簿に使う
- 文字: Zen Kaku Gothic New（Google Fonts）
- ボタンの色の決まりは性癖カルテと同じ（`src/buttons.ts`。主＝その画面でしてほしいこと、副＝見に行く、控えめ＝やめる・コピー、X は黒、消すは赤）
- 画面の文言は `~/.claude/skills/quality-review/design-tips.md` に沿う

## 9. 安全・プライバシー

- 重い相談（死にたい・自傷・虐待・DV など）は AI が印を付け、回答の上に相談窓口を出す。印が無くても、決まった言葉が入っていれば出す（AI の取りこぼしに備える）
- 哲学者の思想はゆがめずに書く。死や苦しみを扱う思想には「思想の紹介で、死を勧めるものではありません」と添える
- 病気・法律・お金の判断はしない（専門家へ、と添える）
- 共有の前に、電話番号・メールアドレス・URL らしきものがあれば知らせる（文字で見分けられるものだけ）
- 共有された相談は通報でき、一定数で自動で隠す。管理画面で隠す・戻す
- AIぬぬはらは「本人の発言ではありません」と明記
- 規約とプライバシー: Gemini の無料枠に相談文が送られ、Google の改善に使われうること／個人が分かることを書かないこと／集計に数として入ること／消し方
- `/api/*`・非公開の相談・管理画面は noindex。共有された相談・名簿・テーマ別の一覧は検索に出す

## 10. テストと確かめ方

- 単体テスト（vitest）: 名簿の形（全員に必要な項目があるか・番号の重複）、指示文の組み立て、答えの読み取りと検証、7人の選び方の直し、近さの計算、重い相談の言葉、テーマの表
- Worker のテスト（@cloudflare/vitest-plugin）: 相談の流れ（偽の AI）、持ち主と共有の権限、刺さった、検索、通報、上限
- E2E（Playwright、偽の AI）: 相談して回答が並ぶ → 補足を開く → 刺さった → 自分の答え → 共有 → みんなの相談に出る → 共有ページを別の人として見る
- 回答の質: `npm run eval`（本物の Gemini。手で読む）

## 11. 開発ルール・レビュー方針

- CLAUDE.md: 入口の表（やること → 最初に読むファイル）、決まり（日本語、区切りでコミットして push、`npm run deploy` は実行しない、キーはコミットしない）
- task.md: 今の状態・決定事項・未決事項・調べた事実
- `quality-review` 用の `~/.claude/skills/quality-review/projects/哲マロ.md`。重点は上から ①哲学者らしさと精確さ（名簿の記述・名言の出典・概念の使い方）②考え方の違いが一目で分かるか（比べ表・補足）③見た目の楽しさと安心感 ④安心（相談という機微な情報・共有の範囲・重い相談）⑤探す・共有 ⑥無料枠を超えないか

## 12. ぬぬはらの操作が要るもの（task.md に手順を書く）

- Gemini API キーを作る（TopicStream とは別のキーにして、無料枠を分ける）→ `.dev.vars` と Worker のシークレット `GEMINI_API_KEY`
- Turnstile のウィジェットを作る → サイトキーを `shared/site.ts`、シークレットを `TURNSTILE_SECRET_KEY`
- Cloudflare で Workers Builds を GitHub のリポジトリにつなぐ・D1 を作る・`tetsumaro.oshilog.life` を割り当てる（oshilog.life がどのアカウントにあるかの確認も）
- 管理画面の合言葉 `ADMIN_TOKEN`
- マシュマロ92件の一般／大人の印を確かめる
