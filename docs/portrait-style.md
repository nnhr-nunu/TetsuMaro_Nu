# 哲学者の絵の決まり

38人を同じタッチでそろえるための決まり。見本は `public/portraits/socrates.svg` と `nietzsche.svg`（ぬぬはらが方向を OK した絵）。

## 形

- ファイル: `public/portraits/<id>.svg`（id は `shared/philosophers` の id）。`<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 200 220">` で始め、width・height は書かない。6KB 以内
- 雰囲気: 上半身のデフォルメを、**面で塗り分けたポリゴン風**のフラットイラストにする（雑誌のような、安心感のあるおしゃれな絵）。16Personalities のような雰囲気だが、絵柄や構図は真似しない
- 使ってよいのは `rect`・`circle`・`polygon`・`ellipse` だけ。**線（stroke）・グラデーション・影のぼかし・filter・文字は使わない**
- 背景: 全面の `rect` に人の色（名簿の color）を白で薄めた色（白8：色2くらい）、その上に `circle cx=100 cy=100 r=78` をさらに薄い色（白9：色1くらい）
- 体: 画面の下端（y=220）まで。肩は y=145〜165 あたり。頭は中心が (100, 85) あたり、幅 56〜64
- 面の分け方: 光は左上から。髪・顔・服・小物のそれぞれを、明るい面（左）と影の面（右）の2〜3段の多角形に分ける。顔は中央の縦の線で左右に分けるのが基本
- 顔: 目は小さな角丸の四角（`#2E2A3D`、幅7〜8・高さ2.5〜3、`rx=1`）。眉は髪の色を濃くした細い多角形。鼻は小さな三角（肌の影の色より一段濃い色）。口は描かないか、ひげで隠す。表情は眉の角度で付ける
- 肌の色（明るい面 / 影の面 / 首 / 鼻）。人の出身に合わせて選ぶ
  - A: `#F6CFAE` / `#E8B48E` / `#E4B08A` / `#D99E78`
  - B: `#E9BC92` / `#D4A177` / `#CF996E` / `#C08A60`
  - C: `#C8916A` / `#B07A55` / `#AA744F` / `#9A6644`
- 人の色（color）を、服の一部か小物のどこか1か所に必ず使う（画面のカードの色とつながるように）
- 右上（x 140〜180、y 30〜75）に、小さな添え物を1つ置いてよい（ポリゴンの宝石、吹き出し、その人にちなむ形）。顔や手に重ねない
- しぐさか小物を1つ。下の表の通り。顔を隠さない
- 喫煙具（パイプ・葉巻・たばこ）は描かない（一般向けのため）
- 宗教の開祖・僧（ブッダ・親鸞・道元）は、おどけさせず穏やかに。ブッダは目を閉じた穏やかな顔
